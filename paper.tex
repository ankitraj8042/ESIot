\begin{abstract}
This paper presents the design of a low-cost, IoT-enabled autonomous mobile robot for indoor transportation. The system achieves PID-based line following, junction-aware node navigation, and real-time obstacle avoidance. Built around an ESP32, it utilizes a five-channel IR array, an HC-SR04 ultrasonic sensor on an SG90 servo for 150\textdegree{} directional scanning, an MPU6050 IMU, and an L298N driver. The robot communicates via MQTT and is managed through a React-based dashboard. Experimental evaluation demonstrates reliable navigation with $\sim$91\% line-following accuracy, $\sim$90\% obstacle detection accuracy, and an average response time under 600~ms. The proposed architecture offers a scalable, affordable solution for autonomous indoor logistics.
\end{abstract}

\begin{IEEEkeywords}
Autonomous Mobile Robot, IoT, ESP32, PID Control, MQTT, Obstacle Avoidance.

\section{Introduction}
Autonomous mobile robots are increasingly deployed in hospitals, warehouses, and smart buildings to automate repetitive indoor transportation tasks. A major challenge in this domain is accurately following predefined paths while avoiding obstacles using resource-constrained hardware. Advanced systems based on computer vision, SLAM, and deep learning \cite{ref2,ref6,ref8} show promising results but demand high computational resources and expensive hardware. Conversely, traditional approaches like the Artificial Potential Field \cite{ref9} and Dynamic Window Approach \cite{ref5} are computationally lighter but often lack remote monitoring capabilities.

To bridge this gap, this work proposes a low-cost autonomous indoor courier robot that integrates PID-based line following, sensor fusion, servo-mounted ultrasonic obstacle scanning, and real-time IoT monitoring. The system uses off-the-shelf components, offering stable navigation, real-time obstacle avoidance, junction-aware delivery routing, and a full MQTT-based IoT dashboard for remote control. Compared to existing solutions \cite{ref1,ref4,ref7}, our approach provides functional performance at a fraction of the cost ($\sim$\$30 USD).

The robot is built on a 4WD chassis. An ESP32 gathers data from a five-channel IR array, an MPU6050, and an HC-SR04 ultrasonic sensor mounted on an SG90 servo for 150\textdegree{} directional scanning. Power is supplied by a 2S (7.4V) Li-ion battery pack protected by a 2S BMS and chargeable via a TP4056. To prevent brownout resets during motor activation, the battery powers the L298N driver directly, while an LM2596 buck converter steps the voltage down to 5V to safely power the ESP32 and logic-level sensors.

The system employs a Node.js MQTT broker. The ESP32 publishes telemetry, obstacle distances, and radar sweeps at 2--5~Hz. A React web dashboard connects via WebSockets, allowing operators to visualize navigation status, tune PID parameters ($K_p, K_i, K_d$), view the live obstacle radar, and issue destination routes (e.g., ``Ward 1'').

\section{Navigation Methodology}

\subsection{PID Line Following \& Node Navigation}
The IR sensor array provides binary line detection with positional weights $w_i \in \{-2, -1, 0, 1, 2\}$. A PID controller computes the steering correction $u(t) = K_p e(t) + K_i \int e(t) dt + K_d \frac{de(t)}{dt}$, where $e(t)$ is the weighted error. Left and right motor speeds are adjusted by adding/subtracting $u(t)$ from a baseline PWM value.

A T-junction is detected when both outer-left and outer-right sensors simultaneously detect the line. Upon detection, the robot executes the next command (Turn Left, Turn Right, Stop) from a predefined route queue. Turns are executed as timed 700~ms pivot maneuvers, aided by the MPU6050 for directional consistency.

\subsection{Obstacle Detection and Avoidance}
The ultrasonic sensor measures distance at 2~Hz. To prevent false positives, three consecutive readings below 15~cm are required to trigger the obstacle avoidance state. Upon confirmation, the robot stops and performs a radar sweep (15\textdegree{} to 165\textdegree{}). Sweep data is published via MQTT for the dashboard's visualizer. The robot then compares left and right clearances, executes a pivot turn toward the greater clearance, and drives forward to search for the original line before resuming PID navigation.

The avoidance maneuver succeeded in 80\% of trials, with occasional failures occurring during the line re-acquisition phase.

\section{Conclusion}
This paper presented an affordable, IoT-enabled autonomous mobile robot capable of PID line following, junction routing, and servo-assisted obstacle avoidance. Utilizing an ESP32 and an MQTT-based web dashboard, the system provides reliable navigation and remote teleoperation at a hardware cost of $\sim$\$30 USD. Future work will focus on integrating camera-based lane detection, SLAM for map-free navigation, and multi-robot coordination.
